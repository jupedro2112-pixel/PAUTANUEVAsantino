R6. Las claves AWS_ACCESS_KEY_ID/SECRET del SSM viejo son credenciales IAM de
    la cuenta vieja: el script YA NO las importa (vínculo entre cuentas).
R7. Región siempre sa-east-1 (São Paulo), en las dos cuentas y en todo.
R8. Navegadores/ventanas separadas para cada consola AWS. No las dos

13. ERRORES CONOCIDOS → SOLUCIÓN
---------------------------------------------------------------------
- "Encryption feature is not supported for engine REDIS" → es create-cache-cluster;
  el script ya usa create-replication-group (etapa redis). Si aparece, git pull.
- "ConfigurationValidationException ... Invalid option specification (Namespace:
  X, OptionName: Y)" en el eb → un option-setting del entorno viejo apunta a un
  recurso/rol de la cuenta vieja. Agregar ese Namespace/OptionName al filtro
  `foreign()` de la etapa eb en scripts/aws-bootstrap-clone.sh, commit, push,
  `git pull`, repetir el eb (dice "app ya existe": normal).
- "CacheClusterNotFound" / SecurityGroups None en el Redis → el nodo se creó sin
  SG explícito. `aws elasticache modify-replication-group --replication-group-id
  clon-redis --security-group-ids <SG default> --apply-immediately --region sa-east-1`
  (la etapa redis actual ya lo pasa al crear).
- "Error parsing parameter '--option-settings': Invalid JSON" → JSON pegado por
  heredoc perdió una coma. Usar la etapa https (printf).
- Prompt "> " después de pegar → la línea se cortó. Ctrl+C y pegar más corto.
- "command not found" con el nombre de un flag (--num-cache-clusters...) → mitad
  de una línea cortada se ejecutó sola; revisar qué se creó a medias
  (describe-*) antes de repetir.
- Navegador "No se puede conectar" en https://EBURL → no hay listener 443 todavía
  (paso 8.2) o Tor Browser fuerza HTTPS. Para pruebas previas al cert usar
  http:// (la PWA carga; el panel NO loguea por HTTP, es normal).
- Panel "Not found" en https://panel.DOMINIO → ADMIN_HOST no coincide o la app no
  reinició tras cambiar el SSM. Verificar:
  aws ssm get-parameter --name SSMPATH/ADMIN_HOST --with-decryption --region sa-east-1 --query Parameter.Value --output text
  y restart-app-server.
- CORS en la PWA (peticiones bloqueadas) → ALLOWED_ORIGINS sin el dominio/www.
- git push falla desde Tails con "Could not resolve host" → corte de DNS de Tor,
  reintentar en unos segundos.
- CloudShell "vacío" al volver → sesión reiniciada; repetir 2.3 (cd + export) y
  recuperar ARN con 3.3. Nada de AWS se perdió.
- Un usuario con la PWA instalada no ve un cambio del front → el service worker
  sirve el JS viejo una carga más (stale-while-revalidate): abrir la app dos
  veces; en iPhone, si persiste, borrar y reinstalar desde Safari.
